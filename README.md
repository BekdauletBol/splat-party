# Splat Party

Браузерный 3D-мультиплеер в мультяшном стиле: шутер от третьего лица без крови, зато с краской, куриной базукой и полётами. Матчи по 5 минут, до 8 игроков в комнате, пустые слоты занимают боты.

## Запуск

Нужен Node.js 20.19 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173. Клиент (Vite) работает на порту 5173, сервер (Colyseus) на 2567.

## Игра с другом в одной сети

1. Запустите `npm run dev`. Vite напечатает адрес `Network: http://192.168.x.x:5173`.
2. Друг открывает этот адрес. Сервер должен быть доступен на порту 2567, поэтому при запросе фаервола разрешите подключения.
3. Создайте комнату и отправьте код из 5 символов или ссылку-приглашение (`?room=ABCDE`). По ссылке друг сразу попадает в лобби.

## Деплой на Render

Сервер Colyseus раздаёт собранный клиент и WebSocket на одном порту, поэтому нужен один веб-сервис.

1. В Render выберите **New → Blueprint** и подключите этот репозиторий.
2. Render прочитает `render.yaml`, соберёт проект и запустит его. Проверка живости: `/health`.

То же локально:

```bash
npm run build
```

```bash
npm start
```

Игра откроется на http://localhost:2567. На бесплатном плане Render сервис засыпает без трафика, а состояние комнат хранится только в памяти, поэтому при перезапуске комнаты пропадают.

## Отладка

Параметры URL клиента:

- `?lag=150` — добавляет 150 мс к пингу (половина на отправку, половина на приём).
- `?loss=5` — теряет 5% инпутов и снапшотов.
- `?dev=1` — панель lil-gui со всеми физическими константами. Изменения идут через сервер и применяются сразу у всех. В production панель работает, только если задана переменная `SPLAT_ALLOW_TUNE`.

Нагрузочный тест: 7 headless-клиентов в одной комнате (сервер должен быть запущен).

```bash
npm run bots -- --clients 7 --secs 30
```

В `tools/bot-client` есть и сквозные проверки: `combat-check.ts`, `bots-check.ts`, `flow-check.ts`. Последнюю удобно запускать на сервере с `SPLAT_MATCH_SEC=6`, чтобы матчи заканчивались быстро.

## Устройство

```
shared/  константы, карты, движение, геометрия попаданий, очки, протокол
server/  Colyseus-комната, бой, боты, физические предметы
client/  Three.js-рендер, предсказание, интерполяция, HUD, меню, звук
tools/   headless-клиенты
```

- `shared/` не импортирует `client/` и `server/`, а они не импортируют друг друга.
- Все физические константы лежат в `shared/src/constants.ts`.
- **Сервер авторитетный**, 30 Hz. Клиент шлёт только инпуты с номером последовательности. Позиции, попадания и урон считает сервер.
- **Предсказание:** свой персонаж движется тем же кодом `stepMotor` из `shared/`. При приходе состояния клиент откатывается к нему и переигрывает неподтверждённые инпуты, а визуальная ошибка плавно гасится.
- **Интерполяция:** чужие игроки рисуются с задержкой около 100 мс между двумя настоящими состояниями.
- **Lag compensation:** сервер хранит историю позиций и проверяет hitscan по положению целей на тик, который видел стрелок (не дальше 300 мс в прошлое).
- **Боты** генерируют такие же `PlayerInput`, как и люди, и идут по тому же коду.
- **Покраска:** сетка клеток считается на сервере, клиент получает изменения и рисует их инстансами-декалями.

## Лицензия ассетов

Внешних ассетов нет: модели собраны из примитивов Three.js, звуки синтезируются в коде.
